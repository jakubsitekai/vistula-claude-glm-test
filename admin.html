Sessions

Open or close a session to control student access. Share the access code with the class (students can also join from the open-session list).

Edit a session

Change the class label, open/close status or the access code. An empty code field leaves the code unchanged; tick "generate a new code" to replace it with a random one. Enforced server-side (staff RPC).

Results

Publishing reveals the score to the students of this session (quizzes with "students see their score immediately" publish automatically).

Student statistics

One row per student per session: number of attempts, last submitted score and date. Data comes from the staff-only student_attempt_stats() RPC — enforced in the database, not just here.

Assignments

Portal-only homework: students submit a GitHub repo / app / PR URL, text or a file. Submissions form a history; grading (status + comment) is teacher-only and enforced in the database.

Kolejne zadania (pomysły)

Pełna wersja: vistula/lecturer/assignments/future-assignments-ideas.md.

  • JSON Schema endpoint — API zwraca JSON o zadanej, stałej strukturze; sprawdzenie: fetch + walidacja kluczy/typów.
  • Counter API z POST — strona z przyciskiem zliczającym; sprawdzenie: GET → POST → GET, wartość +1.
  • Filtr query parameter — API obsługuje parametr (np. ?year=2024); sprawdzenie: wynik z parametrem ⊆ wyniku bez.
  • Statyczna walidacja strony — wymagane pliki (index, about, css); sprawdzenie: HTTP 200 + parse linków.
  • Agregacja danych zespołu — jedna strona pobiera me.json obu partnerów; sprawdzenie: dwa poprawne feche + wzmianki w HTML.

Question bank

Correct answers and explanations are visible here to staff only — students can never retrieve them from the app or database.

User roles

Promote a user to assistant or teacher, deactivate an account (blocks quiz attempts and submissions) or set a class group label. All changes are enforced in the database, not just here.

Studenci (roster)

Lista z dziekanatu (import tools/import-students.mjs). Filtruj po grupie i skreśleniach; uzupełniaj e-mail / login GitHub / grupę. Skreślenia są flagą, nie usunięciem.

Konta testowe (demo)

Stałe konta do ręcznego testowania (indeksy 111111/222222 — poza prawdziwym rosterem). Hasła są także w Windows Credential Manager (ai-environment/vistula/<env>/test-student-1|2) i w materiałach wykładowcy.

Żądania zmian danych

Żądania studentów (pending / used / expired / rejected) z pełnym audytem. Gdy mail nie dotarł (brak adresu), zatwierdź ręcznie jako fallback.
